# 🚀 Motor Control using Arduino

A simple Arduino project to control DC motors (speed & direction) using PWM and motor driver hardware.

---

## 🧠 Project Summary

This project demonstrates how to control one or more DC motors using an Arduino board and a motor driver module (such as L298N or L293D). You’ll be able to control:

- Motor **on/off**
- Motor **direction**
- Motor **speed (using PWM)**

You can use this as a building block for robots, RC cars, or any DC-motor project.

---

## 📦 Components Required

Use the following hardware (example list):

- Arduino board (Uno / Nano / Mega)
- DC Motor(s)
- Motor driver (L298N / L293D)
- External Power Supply (for motors)
- Jumper wires & Breadboard

**Note:** Always use a separate power source for the motor; never power large motors directly from the Arduino.

## 🚀 How to Use

1. **Clone the repo** 
   git clone https://github.com/SUDHANSU-SOLANKI/Motor-Control-using-Arduino.git
   cd Motor-Control-using-Arduino
2. **Open your code**
   Open the .ino file in Arduino IDE
   Set your board & COM port
3. **Upload to Arduino**
   Click Upload
4. **Power the circuit**
   Ensure external motor power is connected
   The motor will start according to your sketch
